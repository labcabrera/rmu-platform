= RMU Engine documentation

Documentation map for the RMU Engine platform. `rmu-platform` describes how the application is run and deployed; each service's code, Dockerfile and image live in its own `labcabrera/rmu-*` repository.

* link:architecture/overview.adoc[Overview]: context diagram, call flow between services, Kafka events.

* link:architecture/frontends.adoc[Frontends]: Module Federation contract, remotes and environment variables.
* link:architecture/configuration.adoc[Configuration]: naming convention of the environment variables, the platform `.env`, legacy names.
* link:architecture/auth.adoc[Authentication]: Keycloak realm, clients, groups and token claims.
