*RMU Engine* is an online assistant for playing link:http://ironcrown.co.uk/unified-rolemaster/[Rolemaster Unified]. It is built from independent APIs (NestJS, Python, Node.js) and React micro-frontends (Webpack Module Federation), each in its own `labcabrera/rmu-*` repository.

This repository holds no application code. It describes *how the application is run and deployed*: the local Docker Compose stack, the Keycloak configuration in Terraform, and the project documentation.

== Quickstart

Requirements: Docker with Compose 2.20+, GNU Make and Terraform 1.6+.

[source,bash]
----
cp .env.example .env
make up                 # infrastructure, APIs, MFEs and tools (COMPOSE_PROFILES in .env)

cp terraform/stacks/keycloak-local/terraform.tfvars.example terraform/stacks/keycloak-local/terraform.tfvars
make keycloak-init      # realm, clients, groups and users in http://localhost:8090
----

`make help` lists every target. See link:docs/local-development.adoc[Local development] for profiles, endpoints and running services from source.

== Repository layout

[options="header",cols="1,3"]
|===
|Path |Contents

|`compose.yaml`, `compose/`
|Local stack, one file per layer: infrastructure, tools, APIs, MFEs, gateway, observability.

|`terraform/`
|Keycloak provisioning (`modules/keycloak`, `stacks/keycloak-local`).

|`scripts/`
|MongoDB backup and restore, starting the MFEs from source.

|`docs/`
|Project documentation. Start at link:docs/index.adoc[].

|`specs/`
|Numbered change proposals (`NNN-<objective>/{spec.md,plan.md}`).
|===
