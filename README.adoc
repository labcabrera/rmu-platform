*RMU Engine* is an online assistant for playing *Rolemaster Unified* games.

The application is divided into APIs developed in *NestJS*, *Python*, and *Express*, along with MFEs developed in *React* using *Webpack* for module federation. Shell manages the authentication and shared components, while each MFE is responsible for a specific domain of the application (core, strategic, tactical, attack items, NPCs, and spells).

It uses *MongoDB* for the persistence of different domains (core, strategic, tactical, attack items, NPCs, and users) and *Kafka* for event communication between different services.

The application uses *OIDC* for authentication, with *Keycloak* as the IAM used.
